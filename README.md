# Portafolio — Mariana Hernández

## Descripción del proyecto

Sitio web de portafolio personal de una página (one-page). Presenta una
sección de perfil con foto e introducción, las habilidades y herramientas de
trabajo, una selección de proyectos destacados con vista previa de imagen, y
una sección de contacto. El sitio es completamente responsivo y se adapta a
tres resoluciones principales: 1440px (escritorio), 768px (tableta) y 320px
(móvil).

## Funcionalidad

- Navegación interna por anclas a cada sección (Perfil, Habilidades,
  Proyectos, Contacto).
- Tarjetas de proyectos con imagen de vista previa, velo degradado para
  resaltar los iconos y etiqueta de herramienta utilizada.
- Enlaces con subrayado en degradado y estados `:hover` en todos los
  elementos interactivos.
- Fondo con efecto de luces (degradados radiales) posicionado en relación
  con el centro de la pantalla.
- Diseño adaptable mediante Flexbox, unidades relativas y `object-fit` /
  `aspect-ratio` en las imágenes.

## Tecnologías y técnicas utilizadas

- HTML5 semántico (`header`, `main`, `section`, `footer`, `ul`/`li`).
- CSS3: Flexbox, `aspect-ratio`, `object-fit`, degradados lineales y
  radiales, `calc()`, `@font-face`, consultas de medios (`767px` y
  `1023px` como puntos de ruptura).
- Metodología BEM para el nombrado de clases.
- Tipografías locales: Open Sans (400/600/700) y Archivo Black (400),
  convertidas a formato `.woff2`.
- `normalize.css` como base de reinicio de estilos.
